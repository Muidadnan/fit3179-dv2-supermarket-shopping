## Implemented in the updated SHOWCASE

- [x] A single scrolling HTML page with CSS.
- [x] 12 separately authored chart specifications: 11 Vega-Lite JSON plus one Vega JSON treemap.
- [x] Three distinct main map idioms: choropleth, proportional-symbol, Dorling cartogram.
